Sistem Pengelolaan Acara & Presensi QR — Arsitektur

Project Capstone Kelompok 7 · Universitas Bakrie · 3-tier web (Client → Application → Data)

Client Layer

  • • 4 aktor: Anggota, Panitia, Pembina, Admin
  • • SPA responsif (Next.js + TS)
  • • QR scanner via kamera browser
  • • Android/iOS, mulai 5" (NFR-07)

Application Layer

  • • REST API + JWT + RBAC
  • • Modul: Event, Proposal, RSVP, Attendance, Report, Member/Notif
  • • QR Generator & Audit Trail (immutable)
  • • Job queue notif H-1 (≤ 5 menit)

Data Layer

  • • PostgreSQL (relasional)
  • • Redis cache & antrian
  • • Object storage (proposal, ekspor)
  • • Audit log append-only

Keamanan & Integritas

  • • Password hashed (bcrypt/argon2)
  • • Auto-logout 30 menit idle (NFR-04)
  • • Presensi immutable + timestamp (NFR-05)
  • • Anti titip/ganda presensi
